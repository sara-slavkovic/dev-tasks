# dev-tasks

Collection of web development tasks built with HTML, CSS, Bootstrap, JavaScript, PHP and MySQL.

## Projects

### 1. CV Page
Responsive CV page built with Bootstrap 5.

### 2. Registration Form
User registration form with JavaScript and PHP validation, AJAX submission.

### 3. Image Slider
Image slider built with Slick carousel library.

### 4. REST API
PHP REST API with layered architecture (Controller, Service, Repository pattern).
- GET endpoint for orders with items
- POST endpoint for user registration with API key authentication

### 5. SQL Queries
MySQL queries on relational database schema (User, Order, OrderItem, Product).

## Technologies
HTML, CSS, Bootstrap 5, JavaScript, PHP 8, MySQL, jQuery, Slick
